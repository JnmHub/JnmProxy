# 前端准备清单

当前阶段不实现前端，只固化页面与接口边界，方便后续单独启动前端阶段。

## 页面清单

1. 仪表盘
   - 总连接数、成功/失败连接数、上传/下载流量。
   - 订阅数量、节点数量、可用节点数量。

2. 订阅管理
   - 订阅列表、创建、编辑、删除。
   - 手动刷新订阅。
   - 展示订阅用量、总量、到期时间、最近刷新状态。
   - 查看刷新日志。

3. 节点管理
   - 节点列表筛选：订阅、协议、分组、启用状态、健康状态。
   - 启用/禁用节点。
   - 单节点健康检查。
   - 批量启用、禁用、加入分组、移出分组。

4. 分组管理
   - 分组列表、创建、编辑、删除。
   - 查看分组节点。
   - 批量添加或移出节点。

5. 关键词分组
   - 关键词规则列表、创建、编辑、删除。
   - 多选规则执行。
   - 全选规则一键执行。
   - 展示本次扫描节点数、触达分组数、触达关系数。

6. 凭证管理
   - 凭证列表、创建、编辑、删除。
   - 重置密码。
   - 绑定全部节点、指定分组或指定节点。
   - 选择随机或固定策略。

7. 流量统计
   - 总览统计。
   - 后续扩展按凭证、节点、订阅、时间趋势查看。

8. 系统设置
   - API 健康状态。
   - 后续扩展运行时配置、日志级别、刷新间隔。

## 前端约定

- API 前缀固定为 `/api/v1`。
- 错误响应统一读取 `error` 字段。
- 时间字段按 RFC3339 或 SQLite `datetime` 字符串展示。
- 创建凭证时只显示一次明文密码，后端不返回密码哈希。
- 节点敏感原始配置后续前端默认折叠展示。
- 先做本地管理端，不默认面向公网。
